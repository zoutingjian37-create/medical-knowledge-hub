# 医学文献讲解的语言动作

本规则来自 32 篇公开医学统计公众号文章的语言蒸馏。学习的是信息组织与解释动作，不是作者人设、品牌口吻或固定句式。来源见 [language-source-manifest.md](language-source-manifest.md)。

## 先选择任务类型

- **原始研究讲解**：围绕一个研究问题，突出设计、方法理由、结果含义和证据边界。默认使用此路线。
- **方法教程**：围绕一个分析决策，增加术语降维、对照微场景和选择流程。
- **数据库指南**：围绕变量可得性、时间结构和适配边界，不承诺“最低工作量”或发表结果。

## 原始研究讲解的语言链

### 1. 开场：场景 → 隐性代价 → 研究主张

用 2–3 句完成：读者面对什么真实场景；现有路径遗漏、拖慢或误判什么；这篇研究试图补上哪一块。不要从期刊、影响因子或作者名单开始。

### 2. 导航：问题 → 短答 → 解释 → 回扣

每节最多设置 1–2 个真正改变推理方向的设问。问题后立即给方向性判断，再解释依据，结尾回扣“这对当前研究判断意味着什么”。

每段 2–4 句。一个段落只完成一个认知动作；不要把 PICO、方法、结果和局限压在同一段。

### 3. 方法：旧方法遗漏 → 新方法补足 → 直观类比 → 类比边界

先指出普通做法会丢失哪类时间、转换、异质性、混杂或预测信息，再解释新方法新增什么。类比后必须映射回正式统计对象，并写明类比没有覆盖的假设。

如果说不清新增信息，就不要把复杂方法写成创新。每项方法同时交代收益、数据门槛、代价、失败条件和退路。

### 4. 结果：判断 → 依据 → 对决策的含义

先写在谁身上观察到什么方向，再保留一个会改变判断的数字或比较，最后说明它影响的是关联解释、风险分层、预测还是临床决策。数字不能脱离参照、时间窗和证据层级。

### 5. 收束：一句提醒就够了

正文以讲清论文为主。只有当读者很可能把结果用错时，才在结尾用 1–3 句说明“这项结果做到哪一步、下一步还缺什么”。不要在研究问题、方法、结果和结尾重复同一条限制，也不要写成审稿意见。

## 术语与类比

- 首次出现术语时使用“熟悉现象 → 最小例子 → 正式定义”。
- 解释机制时使用“主语 → 可核查动作 → 对象 → 中间量/结果”，少用“智能识别、深度挖掘”等空泛能力词。
- 对照案例只改变一个关键条件，展示旧方法为何看不见、新方法新增了什么；案例不充当效果证据。
- 允许克制的“不是 A，而是 B”，但同一节最多一次，且 B 必须由证据支持。

## 图文节奏

- 每张图只回答一个问题。图前告诉读者看什么，图后解释最重要的模式和边界。
- 比较属性用表格；步骤与分支用流程图；状态变化用状态图；数据来源与验证关系用架构图；数值变化才用统计图。
- 原始研究至少提供一张由材料支持的方法图。若原论文图采用 CC BY 等开放许可，优先实际嵌入 1–3 张关键结果图并围绕图片讲解；其他许可只写图号、图意和公开链接。
- 删除装饰图、二维码、录用图、课程图和重复正文的截图；禁止凭空重画 ROC、森林图、机制图或结果图。

## 变化与克制

- 不要机械复现全部动作。每篇通常选择 1 个开场动作、1 个方法解释动作和 1 个结果翻译动作；证据提醒只在确有误读风险时出现一次。
- 标题可以是决策问题或结论式判断，但正文必须兑现；不得制造点击诱饵。
- 不复制来源的固定句式、口头禅、标题结构或连续表达；不得自称来源作者或模仿其人设。
- 保留可核验的期刊、影响因子和分区元数据，但与方法价值、证据质量分开。

## 反风格过滤

删除或改写以下逻辑，而不只是删除关键词：

- 用“高分、一区、总 IF、录用”证明研究重要；
- 用“更高级、热门、顶刊标配”证明方法适配；
- 用审稿焦虑或发表承诺制造问题；
- 用类比替代统计定义、假设和验证；
- 用单篇显著结果证明方法普遍优越；
- 用“直接复刻、最低工作量、一次性达标”替代可行性核查。

## 成文自检

1. 开场是否在 3 句内进入研究问题？
2. 每个设问是否真的改变了下一步推理？
3. 方法段是否说明旧方法遗漏的信息和新方法的代价？
4. 类比是否映射回正式术语并写出止步处？
5. 结果是否说明对谁、相对谁、意味着什么？
6. 局限是否实际削窄了一句结论？
7. 图片是否都有唯一读图任务，且没有装饰图？
8. 删除来源名称后，文字是否仍然成立且看不出在模仿某个作者？
9. 是否为了显得严谨而重复写“边界、不能、并非、尚未”？若是，只保留最必要的一处。
