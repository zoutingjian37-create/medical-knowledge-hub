# 讲解方法审计

本文件记录从多篇医学统计与公共数据库讲解文章中抽取的可复用表达规律。它只保存方法，不复制文章正文或品牌化措辞。

## 当前可执行规律

1. 先给读者一个具体研究决策：为什么普通回归不够、这个设计能解决哪类问题。
2. 先区分方法所回答的问题，再介绍公式或术语；用“结局类型、时间、竞争事件、重复测量”等条件做选择树。
3. 用相邻方法对比减少误用，例如 Logistic、Cox 与竞争风险模型分别回答什么。
4. 用一个研究场景贯穿解释，而不是堆砌定义。
5. 把风险提醒放在方法讲解旁边：适用前提、常见误区和结论不能越过的边界。
6. 结尾落到研究设计启发，但不承诺“照抄即可发表”。

## 视觉叙事规则

1. 图不是装饰：只保留能帮助读者看懂研究设计、变量关系、方法选择或主要结论的图。
2. 全文可核验时，优先引用原论文中对应的图号、图意与公开链接；不把受版权限制的 PDF 截图复制进 Obsidian。
3. 每篇讲解用一张 Mermaid 图重建“人群/数据 → 暴露或干预 → 分析方法 → 结局”的逻辑；图中只放材料明确支持的关系。
4. 结果图、机制图、森林图和 ROC 图不能凭空重画；信息不足时，用文字说明缺口。

待近一个月真实语料完成仓颉三重验证后，更新每条规律的跨文章证据与反例。
